Pick

Pick the agent that is already working.

Handover finds the agents on your machine and lists the ones running right now first. The light tells you which one is live before you send anything.

Running now Installed, idle Model provider unreachable
Drop

Drop anything on it.

Drag a log, a file, a link or a screenshot onto the palette and it fills in your message. Nothing is sent until you press Enter, and the clipboard is never read.

Secrets stay out. .env, keys, certificates and ~/.ssh are refused before they are opened.

Enter send ⇧ Enter newline
Keep going

Every message lands in the same session.

Handover resumes the agent's live session instead of starting a new one, so the agent keeps everything it already knows. What you type is exactly what the agent receives.

Approve

Approve without switching windows.

When an agent stops to ask permission, its row says blocked · approve?. Approve or deny from the palette and the answer goes straight back into its terminal.

It is opt-in, per agent, and only ever on your explicit press.

Privacy

What Handover never does.

Everything runs on your machine. Nothing leaves it unless the agent you pick sends it.

  • Read your clipboardThe palette opens with an empty message. Only what you type or drop goes in.
  • Scan your projectsRunning sessions are found from file names and timestamps, not contents.
  • Open your secrets.env, *.pem, *.key, credentials and ~/.ssh are refused before being read.
  • Listen on the networkThe local service binds to 127.0.0.1, and changes need a local token.
  • Upload anythingHandover has no server. Your agent decides what it sends to its provider.
Install

Two minutes to the first handoff.

One universal download for Apple silicon and Intel. On Linux, build from source.

Download for Mac
  1. Unzip and drag Handover.app into Applications.

    From the latest release on GitHub.

  2. Right-click the app, choose Open, and confirm.

    The build is not signed with an Apple Developer certificate, so macOS asks once.

  3. Allow Accessibility, then press ⌘⇧A.

    System Settings → Privacy & Security → Accessibility lets the global hotkey work.

Build from source 
# Rust (stable), Node 22.12+, and the Tauri prerequisites
git clone https://github.com/thefullctx/handover
cd handover/apps/desktop/ui && npm ci
cd ../src-tauri && ../ui/node_modules/.bin/tauri build

Hand off the next error you see.
